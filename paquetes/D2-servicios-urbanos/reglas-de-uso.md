# Reglas de uso

- Este paquete no contiene datos de terceros. Cada fuente que agregues debe registrar su licencia o términos en `catalogo/fuentes.csv`.
- Si una fuente no permite redistribuir, guarda el enlace y la suma esperada, no el archivo.
- Las fichas de este desafío son mapeo preliminar: no se presentan como cifras oficiales ni como fichas validadas.
- Si encuentras un dato personal, no lo copies y sigue `SECURITY.md`.
